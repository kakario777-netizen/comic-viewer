# comic-viewer

갤럭시(안드로이드)용 만화 뷰어 앱.

## 목표
- FTP 서버의 ZIP 만화를 내려받지 않고 바로 스트리밍으로 보기
- FTP에 접속한 상태에서도 표지 썸네일이 보이는 책장 화면

## 설치 방법
코드가 `main`에 올라가면 GitHub가 자동으로 APK를 만듭니다.
저장소의 **Releases → 최신 빌드 → comic-viewer.apk** 를 폰에서 받아 설치하세요.

## 진행 상황
- [x] 앱 기본 틀 (책장 화면, FTP 서버 추가 창)
- [x] 서버 저장·수정·삭제
- [x] FTP 접속 · 폴더 탐색 (외부 IP, 패시브 모드, UTF-8/EUC-KR)
- [x] 상단 탭 (즐겨찾기 · FTP · 내 폰)
- [x] FTP/내 폰 폴더 즐겨찾기 → 첫 화면에 표시
- [x] 내 폰(내장 메모리·SD카드) 폴더 탐색
- [x] ZIP 표지 썸네일 책장 (ZIP 전체를 받지 않고 목차+첫 이미지만 읽음)
- [x] 설정 화면 (테마: 시스템/밝게/어둡게, 썸네일 캐시 지우기)
- [x] ZIP 스트리밍 뷰어 (페이지별로 읽기, 좌우 넘기기, 탭 영역, 핀치·더블탭 확대, 이어보기)
- [x] 설정: 책장 표지 크기, 넘기는 방향, 썸네일 삭제 2단계 확인
- [x] 회전·폴더블 접기/펼치기에도 화면 상태 유지
- [x] 한 장 / 두 장 / 자동 보기 (뷰어 메뉴 + 설정)
- [x] 책장 표지에 읽은 진행률·다 읽음 표시, 마지막 장 뒤에 다음 권 이어보기
- [x] FTP 동시 연결(1~4개)·미리 받기(2~12장)로 스트리밍 속도 개선
- [x] 진행률 % 표시, 길게 눌러 파일 삭제·진행률 초기화(각각 두 번 확인)
- [x] 볼륨 버튼·블루투스 페이지 터너로 넘기기
- [x] 보는 중 하단에 시간·남은 페이지·% 표시 (설정)
