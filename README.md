# comic-viewer

갤럭시(안드로이드)용 만화 뷰어 앱.

## 목표
- FTP 서버의 ZIP 만화를 내려받지 않고 바로 스트리밍으로 보기
- FTP에 접속한 상태에서도 표지 썸네일이 보이는 책장 화면

## 설치 방법
코드가 `main`에 올라가면 GitHub가 자동으로 APK를 만듭니다.
저장소의 **Releases → 최신 빌드 → comic-viewer.apk** 를 폰에서 받아 설치하세요.

## 진행 상황
- [x] 앱 기본 틀 (책장 화면, FTP 서버 추가 창)
- [x] 서버 저장·수정·삭제
- [x] FTP 접속 · 폴더 탐색 (외부 IP, 패시브 모드, UTF-8/EUC-KR)
- [x] 상단 탭 (즐겨찾기 · FTP · 내 폰)
- [x] FTP/내 폰 폴더 즐겨찾기 → 첫 화면에 표시
- [x] 내 폰(내장 메모리·SD카드) 폴더 탐색
- [x] ZIP 표지 썸네일 책장 (ZIP 전체를 받지 않고 목차+첫 이미지만 읽음)
- [x] 설정 화면 (테마: 시스템/밝게/어둡게, 썸네일 캐시 지우기)
- [x] ZIP 스트리밍 뷰어 (페이지별로 읽기, 좌우 넘기기, 탭 영역, 핀치·더블탭 확대, 이어보기)
- [x] 설정: 책장 표지 크기, 넘기는 방향, 썸네일 삭제 2단계 확인
- [x] 회전·폴더블 접기/펼치기에도 화면 상태 유지
- [x] 한 장 / 두 장 / 자동 보기 (뷰어 메뉴 + 설정)
- [x] 책장 표지에 읽은 진행률·다 읽음 표시, 마지막 장 뒤에 다음 권 이어보기
- [x] FTP 동시 연결(1~4개)·미리 받기(2~12장)로 스트리밍 속도 개선
- [x] 진행률 % 표시, 길게 눌러 파일 삭제·진행률 초기화(각각 두 번 확인)
- [x] 볼륨 버튼·블루투스 페이지 터너로 넘기기
- [x] 보는 중 하단에 시간·남은 페이지·% 표시 (설정)
- [x] 썸네일 갱신은 한 번에 한 폴더씩: 지금 보는 폴더 자동 + 길게 눌러 요청한 폴더 차례로 (없는 표지만, 갱신 중 상단 표시·중지)
- [x] 길게 누르기: ZIP 용량·이미지 수·읽은 위치, 표지 다시 만들기 / 폴더 썸네일 갱신하기
- [x] 하위 폴더는 썸네일 없이 아이콘, 폴더 제목줄에 파일·폴더 개수
- [x] 썸네일 갱신 상세 창 (현재 폴더 13/1000, 대기 폴더 목록·빼기·건너뛰기·모두 중지)
- [x] 페이지 넘김 효과: 슬라이드 / 효과 없이 바로
- [x] 화면이 꺼져도 썸네일 갱신 계속 (포그라운드 서비스 + 알림 진행 표시·중지, 배터리 최적화 예외 버튼)
- [x] 두 번 탭 확대 켜기/끄기 (기본 꺼짐 — 끄면 모든 탭이 즉시 반응)
- [x] 중복 검사: 폴더 지정 → 들어올 때 새 자료 알림, 내용 지문(이미지 CRC)·같은 권 이름으로 묶기, 폴더 안 숨김 기록(.comicviewer_dup.json)으로 바뀐 파일만 재검사, 결과에서 열기·삭제(두 번 확인)
- [x] 중복: '보지 않음'(다음 갱신까지)/'나중에', 처리 안 한 묶음 목록·무시, 위아래(가로면 좌우) 동시 넘김 비교 화면
- [x] 책장 정렬(폴더 위/아래, 이름·날짜·크기, 오름/내림) + 한 달 안에 올라온 안 본 책에 빨간 점
- [x] 이모지를 테두리(외곽선) 아이콘으로 교체, 빌드 시 안 쓰는 코드 정리(R8)
- [x] 압축 오류 검사(길게 누르기): 2중 압축 풀기(원본은 숨김 폴더 보관)·오류 파일 '오류난 파일'로, 썸네일 기억해서 없는 것만, 갱신 후 중복→압축 오류 순서로 자동 확인
- [x] 앱 안 업데이트: 켤 때 자동 확인 + 설정 '업데이트 확인', 받아서 설치 화면까지
- [x] 압축 오류 결과에서 2중 압축 파일 누르기: 안에 든 압축 확인·꺼낼 이름 고치기·바깥 이름 복사(+1,2,3), 다음→다음→목록에서 전체 풀기
- [x] 파일 복사·이동(내 폰↔FTP, 폰 안, 서버 안·서버끼리): 길게 눌러 복사/이동 또는 여러 개 선택 → 옮길 폴더에서 아래 '여기에 붙여넣기', 폴더째 가능·진행률·중지 / 길게 눌러 이름 바꾸기
- [x] 업데이트를 앱 안에서 바로 설치(PackageInstaller) — 두 번째 업데이트부터는 묻지 않고 바로, 끝나면 '업데이트 완료' 알림
